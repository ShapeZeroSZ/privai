PrivAI

Privacy-first terminal UI for Ollama-powered dev assistance. Streams replies, remembers the conversation, and adds your directory and git context to each question. Nothing leaves your machine.

🚀 Quick Start

git clone https://github.com/ShapeZeroSZ/privai
cd privai
make install
ollama pull llama3.2
privai

✨ Features

  • Streaming chat with a local LLM
  • Conversation memory for the whole session
  • Scrollable chat history (↑/↓, PgUp/PgDn)
  • Auto-context: ls, git status, recent commits
  • Env vars: OLLAMA_BASE_URL, OLLAMA_MODEL
  • Bubble Tea TUI (Enter send, Esc then q or Ctrl+C quit)

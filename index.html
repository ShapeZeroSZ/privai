PrivAI

Privacy-first terminal UI for Ollama-powered dev assistance. Streams responses, injects files/git context.

🚀 Quick Start

git clone <repo>
cd privai
make install
ollama pull llama3.2
privai

✨ Features

  • Streaming chat with local LLM
  • Auto-context: ls, git status/commits
  • Env vars: OLLAMA_BASE_URL, OLLAMA_MODEL
  • Bubble Tea TUI (keys: Enter send, q quit)
